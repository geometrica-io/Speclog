# Speclog v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** VS Code (ve VS Code tabanlı editörler) için, birden çok repodaki görevleri `docs/tasks`, Backlog.md ve Spec Kit dosyalarından okuyup durumunu git'ten doğrulayan, ProjectManager ekranının karşılığını sunan bir eklenti (Speclog v1).

**Architecture:** npm workspaces monoreposu. `packages/core` VS Code'dan bağımsız saf TypeScript (Node `child_process` ile `git`): ProjectManager (PM) C++ çekirdeğinin modül modül çevirisi + adaptör katmanı + yeni "Doğrulanmadı" kuralları. `packages/vscode` eklenti ana süreci (motoru barındırır, komutlar, ayarlar, durum çubuğu) + webview arayüzü (çerçevesiz TS, esbuild ile paketlenir). Webview ile eklenti arasında tipli mesaj protokolü.

**Tech Stack:** TypeScript 5 (strict), Node ≥ 20, npm workspaces, vitest (core testleri), esbuild (eklenti + webview paketleme), `yaml` (Backlog.md ön bilgisi), `@vscode/l10n`, `@vscode/test-electron` (eklenti duman testi), `@vscode/vsce`, `ovsx`, GitHub Actions.

**Spec:** `docs/superpowers/specs/2026-11-11-speclog-design.md`. Öncül kod (çevrilecek, salt okunur): `C:\Antigravity\ProjectManager\src\core\*` ve `C:\Antigravity\ProjectManager\tests\*` (+ `tests\hooks\`), PM spec'i `C:\Antigravity\ProjectManager\docs\superpowers\specs\2026-11-08-project-manager-design.md`.

## Global Constraints

- `packages/core` hiçbir yerde `vscode` modülünü import etmez; testleri yalnız core'a bağlanır.
- Speclog hiçbir görev dosyasını değiştirmez. Tek yazma: kullanıcının çalıştırdığı "Install commit-msg hook" komutu. Tek yazan git komutu: `git fetch --prune origin` (yalnız `refs/remotes/origin/*`).
- Görev dosyaları çalışma ağacından değil git'ten okunur (ana dal ucu + birleşmemiş dallardaki yalnız-dalda maddeler) — her üç biçim için.
- Her git çağrısı: `GIT_TERMINAL_PROMPT=0`; fetch ek olarak `GCM_INTERACTIVE=never`, `-c credential.interactive=false`, `-c http.lowSpeedLimit=1 -c http.lowSpeedTime=60`, kullanıcı ayarlamadıysa `GIT_SSH_COMMAND=ssh -o BatchMode=yes -o ServerAliveInterval=15 -o ServerAliveCountMax=4`; fetch zaman aşımı 60 s, diğerleri 120 s. Ref'ler tam adla (`refs/heads/…`, `refs/remotes/…`), `--end-of-options`, revizyon listeleri `--stdin` ile.
- Ana dal ölçütü: commit `origin/<d>` **ya da** yerel `<d>`'den ulaşılabiliyorsa ana dalda; `<d>` = `origin/HEAD` hedefi, yoksa `main`, sonra `master`.
- Durumlar: `open, partial, bug, verify, decision, dropped, done, onBranch, unverified`. `unverified` yalnız elle durum yazılan biçimlerde (Backlog.md, Spec Kit) ve ayar `speclog.unverifiedDone` = `"unverified"` (varsayılan) iken; `"done"` → done + işaret + Dikkat; `"open"` → dosyadaki bitti yok sayılır.
- Kimlik karakterleri `[A-Za-z0-9._/-]`; `docs/tasks` ve Spec Kit büyük/küçük harfe duyarlı, Backlog.md duyarsız. Spec Kit kimliği `<özellik-klasörü>/T###`.
- Repo adı = `origin` adresindeki depo adı (yoksa klasör adı); `Task: <Ad>:<id>` ve `Task: <sahip>/<ad>:<id>` büyük/küçük harfe duyarsız; repo başına ayar anahtarı = `origin` URL'si (yoksa mutlak yol).
- Ayarlar (varsayılanlar): `speclog.roots` = `[]`, `speclog.exclude` = `[]`, `speclog.originFilter` = `[]` (boş = hepsi), `speclog.fetch.enabled` = `true`, `speclog.fetch.intervalSeconds` = `300`, `speclog.staleBranchDays` = `7`, `speclog.unverifiedDone` = `"unverified"`. Arayüz durumu `workspaceState`; repo kesimleri ve gizlenen repolar `globalState` (repolara yazılmaz).
- Eklenti: `extensionKind: ["workspace"]`, tek universal paket, yayımcı `geometrica`, ad `speclog`, görünen ad "Speclog", lisans MIT, telif "Geometrica.io". Dil: İngilizce varsayılan + Türkçe (`package.nls.tr.json`, `l10n/bundle.l10n.tr.json`).
- Webview: yalnız `--vscode-*` tema değişkenleri; açık / koyu / yüksek karşıtlık; bütün yazılar aynı boyut; Content-Security-Policy ile yalnız yerel script; klavyeyle gezilebilir.
- Kod yorumları İngilizce ve kısa; LF; commit mesajları kısa, emir kipinde, `Co-Authored-By` satırı yok.
- Komutlar: `npm ci`, `npm run build`, `npm test` (core vitest), `npm run test:ext` (eklenti duman testi), `npm run package` (vsix).

## Review Focus

1. **Windows yolları:** boşluk ve Türkçe karakter içeren repo yolu/dosya adı ile git çağrıları ve görev dosyaları bozulmadan çalışmalı (Task 3, 4 testleri).
2. **Büyük repo / yavaş git:** SFEA boyutunda bir repo taranırken arayüz donmamalı, kapatma ve yenileme taramayı iptal edebilmeli (Task 10 testi: iptal edilen tarama yayımlanmaz).
3. **Backlog.md'nin kendine özgü ayarları:** `config.yml` yok ya da özel durum adları ("Backlog", "Doing", "Shipped") — ilk/ara/son durum eşlemesi config'teki sıraya göre yapılmalı, config yoksa Backlog.md varsayılanları (Task 5 testi).
4. **Aynı repo iki kez:** çalışma alanı klasörü ve `speclog.roots` aynı repoyu (ya da worktree'sini) gösterdiğinde repo bir kez görünmeli (Task 4 testi: realpath ile tekilleştirme).
5. **Git yok / eski git:** PATH'te git yoksa ya da `--end-of-options` desteklemeyen eski bir sürümse (git < 2.24) eklenti çökmeden tek, açık bir hata gösterir (Task 3 testi: git sürümü kontrolü).
